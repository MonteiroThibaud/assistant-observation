# Historique des versions

Les versions 0.xx sont des versions de test, avant la version 1.

## 1.0 — 25 novembre 2026 (première version diffusée)
- Version 1.0 : le code de l'application est celui de la 0.97 (aucune modification) ; changent le numéro et la date, le lien du code source (GitHub) dans « Droits d'utilisation et crédits », `CITATION.cff` et `codemeta.json` (version 1.0.0, adresse du dépôt). Les nouveautés depuis la 0.95 sont décrites dans la section 0.97 ci-dessous. À partir de la 1.0, les données enregistrées sur l'appareil (carnet, lieux, réglages) restent lisibles d'une version à l'autre ou sont migrées.
